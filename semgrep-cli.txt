# CODESCAN（自アプリのコード脆弱性診断）用の静的解析エンジン semgrep。
# app/codescan/crawler.py が subprocess で `semgrep` CLI を呼ぶだけで、Pythonから
# importしないため、アプリの依存（requirements.txt）とは別のvenv（/opt/semgrep-venv、
# Dockerfile参照）にインストールする。aarch64向けmanylinuxホイールが公式提供されて
# いるためOCI本番（ARM64）でも動作する。Windowsでは動作しない（開発環境ではモック）。
#
# 隔離している理由: semgrepはpyjwt~=2.13.0・mcp・click等を厳密にピン留めして依存する。
# 同じ環境に入れるとアプリのPyJWTを脆弱性修正済み（2.15以降）に上げられず、semgrepを
# 古い版に固定するとmcp・click側の別の脆弱性が出る（実際にpip-auditで確認）。
# なおファイル名を requirements*.txt にしないのは、pip-audit/OSV-Scannerの走査対象を
# アプリ本体の依存（requirements.txt）に限定するため。semgrep側の既知の脆弱依存は
# Dockerfileで個別に上書きしている（PyJWT）。
semgrep>=1.100.0
